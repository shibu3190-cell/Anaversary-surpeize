# Celebration Link Creator

1. **Open the site** (index.html).
2. **Fill in the details**: Title, Message, and Password.
3. **Click "Create & Copy Link"**: The link is automatically copied to your clipboard.
4. **Send the Link**: Paste and send that link to her.
